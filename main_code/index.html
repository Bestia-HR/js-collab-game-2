Ucieczka z serwerowni

Otwórz konsolę dewelopera (F12 → Console) i steruj grą numerami: g() pokazuje menu, g(2) wybiera pozycję. Pełna lista poleceń: gra.pomoc(). Instrukcja zapisu i wczytywania postępu jest w README.md.

Reguły gry są w engine.js, obsługa konsoli w app.js. Po zapisaniu zmian odśwież stronę.
